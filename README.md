# 🌐 Site da Igreja Filadélfia

Este projeto é o site oficial da **Igreja Filadélfia**, desenvolvido com o objetivo de apresentar informações essenciais sobre a igreja, como os horários dos cultos, localização, galeria de fotos e áreas especiais como a **Escolinha para crianças** e o grupo de jovens **Juventude Filadélfia**.

## 🎯 Propósito

O site foi criado para facilitar o contato com novos visitantes e membros da igreja, além de servir como um canal de comunicação e apresentação visual da Igreja Filadélfia. Também funciona como um projeto de portfólio pessoal, destacando habilidades em desenvolvimento web.

---

## 🛠️ Tecnologias Utilizadas

- 🧱 **HTML5**  
  Utilizado para estruturar todo o conteúdo da página com semântica e acessibilidade, usando tags como `<header>`, `<main>`, `<section>`, `<footer>`, entre outras.

- 🎨 **CSS3**  
  Responsável pela estilização do site, utilizando paleta de cores harmônica com base na identidade visual da igreja, efeitos visuais com `box-shadow`, `border`, e layout moderno.

- 🔍 **SEO (Search Engine Optimization)**  
  Aplicado de forma básica através de boas práticas em marcação semântica, uso de tags apropriadas e organização hierárquica de conteúdo para melhor indexação nos motores de busca.

- 📱 **Responsividade** *(em andamento)*  
  O site está sendo ajustado para funcionar bem em diferentes tamanhos de tela, como smartphones e tablets.

---

## 📷 Funcionalidades

- 🎞️ Slide automático de imagens logo no carregamento do site
- 📌 Seções com informações claras:
  - 🕊️ Sobre Nós
  - ⏰ Horários dos cultos
  - 📍 Endereço da igreja
  - 🧒 Área das Crianças (com fotos e descrição)
  - 🙌 Convite para novos visitantes
  - 🖼️ Galeria de fotos da igreja
  - 📞 Rodapé com contatos
